# CodeAlpha Full Stack Development Internship Projects

Two full stack projects built with **HTML, CSS, JavaScript, Node.js, Express.js and SQLite**.

| Project | Folder | Description |
|---------|--------|-------------|
| Task 1 | [EcommerceStore](./EcommerceStore) | Simple e-commerce store: products, cart, login, orders |
| Task 2 | [SocialMediaApp](./SocialMediaApp) | Mini social media app: profiles, posts, comments, likes, follow |

## Run a project
Requires Node.js 22.5 or newer.

```bash
cd EcommerceStore      # or SocialMediaApp
npm install
npm start
```
Then open http://localhost:3000

See the README inside each folder for features, database tables and screenshots.
